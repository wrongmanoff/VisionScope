# VisionScope Submission Checklist

## Code
- [ ] `pytest` passes immediately before submission.
- [ ] CLI help works.
- [ ] All required modules import correctly.
- [ ] No debug prints or temporary files remain.
- [ ] `.venv` and caches are excluded from Git.

## Demonstration
- [ ] Image preprocessing demo prepared.
- [ ] Feature/segmentation demo prepared.
- [ ] Geometry demo prepared.
- [ ] Stereo/depth demo prepared with valid stereo inputs.
- [ ] Motion demo prepared with two consecutive frames.
- [ ] Benchmark results generated.

## Report
- [ ] Problem statement.
- [ ] Objectives.
- [ ] Functional requirements.
- [ ] Nonfunctional requirements.
- [ ] Architecture/workflow.
- [ ] Algorithms and rationale.
- [ ] Dataset/input description.
- [ ] Evaluation methodology.
- [ ] Actual results.
- [ ] Limitations.
- [ ] Future work.
- [ ] Screenshots/figures.

## Academic integrity
- [ ] Results are measured, not invented.
- [ ] Sources/citations are genuine.
- [ ] Custom implementations are explicitly identified.
- [ ] Library implementations are explicitly identified.
